# Recommended GitHub repository settings

These changes are prepared but were not applied because GitHub CLI is not authenticated on the maintainer workstation.

## Description

> Cross-platform .NET MAUI bedding catalogue with seasonal weather-aware recommendations, local search, and saved products.

## Topics

`dotnet-maui`, `aspnet-core`, `postgresql`, `android`, `windows`, `retail`, `bedding`, `product-catalog`, `open-meteo`, `cross-platform`

## Settings to review

- Keep `main` as the default branch.
- Require the `Windows build` and `Android build` checks before merge after the workflow has passed once.
- Enable private vulnerability reporting.
- Enable Dependabot security updates and review dependency pull requests.
- Delete head branches after pull requests are merged.
- Consider GitHub Discussions only when there is enough community traffic to maintain it.

Do not enable a website URL, sponsor link, or social preview that has not been verified.
