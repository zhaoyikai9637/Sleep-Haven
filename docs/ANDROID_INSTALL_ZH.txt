SleepHaven 手机离线安装说明
==========================

文件说明
  SleepHaven-Android-arm64-v1.0.apk 是已经签名的 Android 安装包。
  SHA256.txt 用于核对安装包在传输后是否完整。
  在 Windows PowerShell 中可运行 Get-FileHash -Algorithm SHA256 <APK完整路径>，结果应与 SHA256.txt 一致。
  此压缩包不包含源码、签名私钥或任何需要在手机上额外下载的运行时。

适用范围
  适用于 ARM64（arm64-v8a）且 Android 7.0 或更高版本的手机。
  荣耀 MagicOS、华为 EMUI，以及仍支持直接安装 Android APK 的华为系统，可按下述步骤安装。
  HarmonyOS 5 / NEXT 及更新版本不能保证直接离线安装此 APK：是否可通过“卓易通”等兼容服务安装，以手机实际支持为准。本包不是鸿蒙原生 HAP。
  尚未在你的具体华为或荣耀机型上进行实机测试，因此不能保证所有机型、系统版本都兼容。

从电脑取得安装包
  1. 在 Codex 中点开提供的本地 ZIP 链接，或在电脑上打开 E:\SleepHavenMobile 找到该 ZIP。
  2. 用 USB 数据线连接手机和电脑，在手机通知中选择“传输文件”。
  3. 将 ZIP 复制到手机的 Download（下载）文件夹。复制完成后可拔线。
  4. 无须把电脑上的整个项目文件夹复制到手机。

在手机安装和打开
  1. 打开手机“文件管理”，进入“下载”或 Download，点开 ZIP 并解压。
  2. 在解压后的文件夹里点击 SleepHaven-Android-arm64-v1.0.apk。
  3. 若系统询问是否允许“文件管理”安装外部来源应用，只对这一次可信安装开启该来源权限，然后返回安装界面继续。
     常见路径：设置 > 安全 > 更多安全设置 > 安装外部来源应用 > 文件管理 > 允许安装应用。
     不同 MagicOS、EMUI 版本的名称可能略有不同。
  4. 安装完成后点击“打开”，以后也可在桌面或应用列表点击 SleepHaven 图标。
  5. 安装结束后可以把“文件管理”的外部来源安装权限重新关闭。

联网与数据
  APK 的传输和安装可以全程离线。商品资料和图片保存在应用内，离线也能浏览。
  天气与季节推荐需要联网查询 Open-Meteo；断网时该卡片会提示天气不可用，仍可手动切换季节。
  应用目前只提供 Singapore / Qingdao 两个城市按钮，不会自动读取手机 GPS 位置。

遇到问题
  提示“无法解析安装包”或“设备不兼容”：检查手机是否为 ARM64 且 Android 7.0 以上，并确认 ZIP 已完整解压。
  提示“签名不一致”：手机上可能安装过另一把密钥签名的同包名测试版。卸载旧版可能清除应用内的收藏、购物车等本地数据，请先确认可以接受，再卸载后安装本包。
  系统安全扫描明确判定风险时不要强行绕过；先核对来源及 SHA256，再进一步排查。
  HarmonyOS 5 / NEXT 不能直接安装时，需要该设备支持的 Android 兼容服务，或另行开发鸿蒙原生版本。
